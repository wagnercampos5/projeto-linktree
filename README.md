# 🔗 Linktree Personalizado | Wagner Julio de Campos

Página de links personalizada desenvolvida do zero para atuar como um "cartão de visitas digital". O objetivo deste projeto é centralizar meus principais links (Portfólio, GitHub e LinkedIn) e compartilhar meu progresso enquanto estudo para me tornar um **desenvolvedor Full Stack, Mobile e criador de soluções com IA**.

Recentemente, o projeto passou por um **refatoramento de UI/UX**, adotando a paleta de cores *Midnight Sky*, efeitos de *Glassmorphism* (vidro temperado) e tipografia moderna.

## 🚀 Tecnologias e Técnicas Utilizadas

O projeto foi construído utilizando tecnologias web fundamentais (HTML e CSS puros), focando no aprimoramento da sintaxe, estruturação semântica e design moderno:

* **HTML5 Semântico:** Uso de tags como `<main>`, `<footer>` e `<ul>` para melhor acessibilidade e estruturação.

* **CSS3 Moderno:**

  * **Variáveis CSS (`:root`):** Para gerenciamento eficiente do tema de cores (Dark Mode).

  * **Glassmorphism:** Efeito visual de vidro semi-transparente utilizando `backdrop-filter: blur()`.

  * **Sombras e Profundidade:** Uso de `box-shadow` e `transform: translateY` para criar interatividade tátil nos botões.

* **Flexbox:** Construção de um layout centralizado, fluido e responsivo.

* **Integração de CDNs:**

  * **Google Fonts:** Tipografia *Poppins* para um visual limpo e geométrico.

  * **Font Awesome:** Inclusão de ícones vetorizados nos botões para melhorar a navegabilidade e UX.

## 🛠️ Aprendizados Principais

Durante o desenvolvimento e as recentes atualizações deste projeto, pratiquei conceitos essenciais de Front-End:

1. **Design Responsivo e Segurança de Tela:** Ajuste de alinhamentos (`align-items: flex-start`) e paddings (`padding: 32px 16px`) para garantir que o conteúdo não seja cortado em telas de smartphones menores.

2. **Manutenibilidade de Código:** O uso de Custom Properties (variáveis CSS) permitiu alterar toda a paleta de cores do site mudando apenas as declarações no topo do arquivo.

3. **Estilização Avançada:** Trabalhar com opacidade (`rgba`), contrastes acessíveis e espaçamentos (`gap`) em containers Flexbox.
