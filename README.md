# 🔗 Projeto Linktree - Wagner Julio

Este é um projeto de uma página de links pessoal, estilo Linktree, desenvolvida totalmente do zero com o objetivo de praticar a escrita manual de código, estruturação semântica e estilização moderna.

A página foi criada para centralizar minhas principais redes sociais e compartilhar meu progresso enquanto estudo para me tornar um desenvolvedor Full-Stack.

## 🚀 Tecnologias Utilizadas

O projeto foi construído utilizando tecnologias web fundamentais, sem o uso de frameworks, focando no aprendizado da sintaxe pura:

- **HTML5:** Estruturação semântica do conteúdo (títulos, parágrafos, listas e links).
- **CSS3:** Estilização global, definição de esquema de cores (Dark Mode), tipografia e efeitos visuais.
- **Flexbox:** Utilizado para criar um layout de coluna perfeitamente centralizado e responsivo.
- **Pseudoclasses (`:hover`):** Implementação de transições suaves e interatividade nos botões ao passar o mouse.

## 🛠️ Aprendizados Principais

Durante o desenvolvimento deste projeto, pratiquei conceitos essenciais de Front-End:
1. **Caminhos Relativos:** Organização e importação correta de arquivos locais (como a foto de perfil dentro da pasta `assets`).
2. **Reset de CSS:** Limpeza de margens e preenchimentos padrões dos navegadores para garantir total controle do layout.
3. **Responsividade Base:** Uso de propriedades como `max-width` para garantir que a leitura fique confortável tanto em telas de computadores quanto em dispositivos móveis.
